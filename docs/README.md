# Описание решения

## Задание

Интеграция программных компонентов с применением шаблонов **Adapter (Адаптер)** и **Facade (Фасад)**.

В проекте есть два несовместимых интерфейса часов:

- `BaseAnalogClock` — аналоговые часы: время хранится как **углы стрелок** (`hour_angle`, `minute_angle`, `second_angle`) и признак `AM/PM`;
- `BaseDigitalClock` — цифровые часы: время хранится как `datetime`.

Клиентский код должен работать только с `datetime`, поэтому аналоговые часы напрямую использовать нельзя — нужен адаптер.

## Adapter — `DigitalClockAdapter`

`DigitalClockAdapter` реализует `BaseDigitalClock` и через **композицию** держит внутри объект `BaseAnalogClock`.

- `set_date_time(datetime)` — раскладывает `datetime` на углы и `AM/PM`, вызывает аналоговый `set_date_time`:
  - `hour_angle = (hour % 12) * 30`
  - `minute_angle = minute * 6`
  - `second_angle = second * 6`
  - `AM` при `hour < 12`, иначе `PM`
- `get_date_time()` — обратное преобразование углов и `AM/PM` обратно в `datetime`.

Адаптер решает проблему **несовместимости интерфейсов**: превращает аналоговый интерфейс в цифровой.

## Facade — `ClockFacade`

`ClockFacade` даёт клиенту единый компактный интерфейс и скрывает взаимодействие с адаптером, `ClockFormatter` и `ClockHistory`.

Особенность этого варианта: фасад принимает **произвольный набор часов** (`*args`), которые могут быть как аналоговыми, так и цифровыми:

- `add_clocks(clock)` — если передан `BaseAnalogClock`, оборачивает его в `DigitalClockAdapter`; если уже `BaseDigitalClock` — использует напрямую;
- `set_time(datetime)` — устанавливает время во все часы и пишет значение в историю;
- `get_time(idx)` — время конкретных часов;
- `get_time_format(idx, fmt)` — форматированное представление;
- `get_time_history()` — история изменений.

Фасад решает проблему **сложности подсистемы**: клиенту не нужно знать, какие часы есть и нужно ли их адаптировать.

## Ключевое различие

| Паттерн | Задача |
|---|---|
| **Adapter** | Преобразует один интерфейс в другой (`datetime` ↔ углы/AM-PM) |
| **Facade** | Предоставляет простой интерфейс к подсистеме из нескольких объектов |
